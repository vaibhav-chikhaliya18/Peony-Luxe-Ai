# Peony Luxe AI — Luxury Creative AI Studio Website

A cinematic, high-end digital portfolio and web experience for **Peony Luxe AI**, showcasing AI Films, Brand Stories, and Next-Gen Digital Production.

![Peony Luxe AI Preview](public/images/hero/hero-bg.jpg)

---

## ✨ Features

- **Cinematic Visuals & Motion:** Smooth page transitions, parallax image animations, and Lenis smooth scrolling.
- **Hero & Interactive Video:** Hero section with custom branding, animated reel previews, and video modal player.
- **Dynamic Portfolios:**
  - AI Films & Cinematic Commercials showcase
  - Brand Stories & Digital Campaigns
  - Interactive Project Details with gallery and behind-the-scenes
- **Modern Responsive Design:** Crafted with Tailwind CSS and Framer Motion for flawless responsive luxury aesthetics across all screen sizes.
- **Interactive UI Components:** Magnetic buttons, glowing interactive cards, custom drawer menus, and preloader.

---

## 🛠️ Tech Stack

- **Framework:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://gsap.com/)
- **Smooth Scrolling:** [Lenis](https://lenis.darkroom.engineering/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Routing:** [React Router DOM v6](https://reactrouter.com/)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd "Peony Website"
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
